## Geeplo

Geeplo builds governance tooling for Google Workspace. One console, two jobs done well:

- **ShareGuard** - find every file shared outside your company, rank the risk, revoke stale shares on a schedule.
- **Transfer Tool** - tenant-to-tenant migration: users, drives, mail, calendars, with checkpoint resume.
